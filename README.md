## ✨ Features

- 🌙 **Premium Dark Theme** — Deep navy background with cyan-to-purple gradient accents
- 🪟 **Glassmorphism Design** — Frosted glass cards with backdrop-blur effects
- ⌨️ **Typewriter Animation** — Dynamic role cycling in the hero section
- 🎯 **Scroll Reveal Animations** — Smooth, performance-optimized reveal effects using IntersectionObserver

- 🔄 **Interactive Elements** — Hover effects, glowing cards, spinning gradient ring
- 📬 **Working Contact Form** — Integrated with Web3Forms API
